# AURA Animation Studio Workspace 🎬✨
### Collaborative Production Hub for Indie Animation Teams (5-Artist Pipeline)

A modern, high-performance, full-stack **Animation Production Workspace & Collaboration Hub** tailored for an indie team of 5 artists working on animated short films.

---

## 🎨 Visual Design & Theme System (Warm Minimalist / Ivory & Cream Aesthetic)

- **Canvas & Background:** Soft warm cream, subtle champagne gradient, and delicate ivory (`#fcfaf6` to `#f6efe3`).
- **Surface & Cards:** Crisp porcelain white (`#ffffff`) with ultra-fine organic borders (`border-[#e9e3d8]`) and diffused ambient shadows.
- **Typography:** Deep warm graphite (`#1c1917`), muted slate (`#78716c`), and cinematic serif accents for editorial film titling.
- **Accents:** Warm golden honey / refined amber (`#d97706` / `#b45309`), soft sage green for approved milestones, and terracotta for revision notes.

---

## 🏛️ Architecture & Unified Production Modules

1. **Studio Overview & Milestones:**
   - Real-time pipeline health calculation, total frames & runtime cut calculator, delivery countdown, and 7-stage distribution.
2. **Screenplay & Scene Script Editor:**
   - Standard screenplay typesetting (Sluglines, Action, Character, Parenthetical, Dialogue) with beat insertion and clipboard export.
3. **Storyboard Frame Sequencer:**
   - Visual grid of frames with camera motion tags (`Slow Dolly In`, `Tracking Shot`), shot framing, duration counters, audio cues, and fullscreen Lightbox preview.
4. **Animation Shots Board (7 Stages):**
   - Dual-view (Kanban Board & Table List) tracking `Script` → `Layout` → `Keyframe` → `In-Between` → `Color & FX` → `Composite` → `Approved`.
   - 1-click stage advancement, complexity badges, assignee avatars, and priority filters.
5. **Voiceover & Audio Lab:**
   - Multi-take audition player, dynamic animated waveform visualizer, 5-star rating system, Master Mix selection, and atmospheric Foley library.
6. **Video Renders & Review Suite:**
   - 2.39:1 anamorphic cinematic player, timecode scrub bar (`00:00:00:00`), and interactive timecoded director comment pins.
7. **Indie Team Collab Room (5 Artists):**
   - Director, Lead Animator, Storyboard Lead, Sound Designer, and Compositor workspace with real-time style message stream and `#Shot` tagging.
8. **Context-Sensitive Inspector (Right Panel):**
   - Frame range calculator, lead assignee selector, director continuity notes, and instant Director Sign-Off Approval celebration!

---

## ⚡ Tech Stack

- **Frontend:** React 19 + TypeScript + Vite 8
- **Styling:** Tailwind CSS v4 (Warm Cream & Ivory theme tokens)
- **Icons:** Lucide React
- **Edge Backend:** Cloudflare Pages Functions (`functions/api/*`)
- **Database:** Cloudflare D1 (Serverless SQLite Relational Database via `schema.sql`)
- **Media Assets:** Cloudflare R2 (`/api/upload`) with offline local fallback
- **Runtime & Package Manager:** Bun / Node.js

## 🚀 Getting Started

### 1. Run Development Server Locally
```bash
bun install
bun run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 2. Build for Production
```bash
bun run build
```

---

## ☁️ Deploying to Cloudflare Pages

### 1. Login to Cloudflare Wrangler
```bash
wrangler login
```

### 2. Create the Cloudflare D1 Database
```bash
wrangler d1 create animation-studio-db
```
Copy the `database_id` generated by Wrangler into [wrangler.toml](file:///C:/antigravity%20project/Animation/wrangler.toml):
```toml
[[d1_databases]]
binding = "DB"
database_name = "animation-studio-db"
database_id = "<YOUR_DATABASE_ID>"
```

### 3. Initialize the D1 Schema
```bash
bun run db:migrate
```

### 4. Deploy to Cloudflare Pages
```bash
bun run deploy
```
or connect your GitHub repository directly to **Cloudflare Pages** for automated Git deployments on push!
